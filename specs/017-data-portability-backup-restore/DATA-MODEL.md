# Data Model - Data Portability, Backup and Restore

**Status:** IN_REVIEW - pending owner acceptance of B-41; does not authorize implementation; not a claim of implementation or qualification.
**Feature:** 017 | **Authority:** [STORAGE.md](../../docs/STORAGE.md) "Backup and disaster recovery", [DATA-MODEL.md](../../docs/DATA-MODEL.md), [SECURITY.md](../../docs/SECURITY.md), [EVENTS.md](../../docs/EVENTS.md).

This package reuses the canonical Workspace records and must not create a parallel copy of any domain aggregate. A backup is a sealed file; the only new durable record is the operation lifecycle row.

## 1. Existing durable records

| Record | Identity and scope | Owner | Feature use |
|---|---|---|---|
| `workspace_backup_manifests` | `backup_id` PK; `workspace_id`; immutable (trigger `immutable_workspace_backup_manifest_update`) | Storage | Published only after read-back verification; listed in Settings |
| `context_document_purge_plans` | sealed purge target manifest per ContextDocument | Feature 003 / Storage | Carried; drives Deletion status |
| `context_document_purge_receipts` | per-target acknowledgement | Feature 003 / Storage | Carried; ACKNOWLEDGED targets never reintroduced |
| `capability_grants` | grant identity within Workspace | Trust | Carried and set REVOKED on restore/import |
| `runtime_incarnations` | Runtime incarnation | Runtime | Carried and set STOPPED; a new identity is minted on first start |
| Excluded tables | the 26 names in `BACKUP_EXCLUDED_TABLES` | Runtime-local owners | Never carried |

## 2. PROPOSED new record (accepted target interface after acceptance; not yet in source)

`backup_operations`:

| Column | Type | Rule |
|---|---|---|
| operation_id | TEXT PK | Generated by the daemon |
| principal_id | TEXT | From authenticated IPC peer |
| workspace_id | TEXT NULL | NULL only for verify of an archive not yet bound to a local Workspace |
| kind | TEXT | CREATE, VERIFY, IMPORT |
| mode | TEXT NULL | INSTALLATION_BACKUP, PORTABLE_EXPORT (CREATE only) |
| state | TEXT | QUEUED, RUNNING, SUCCEEDED, FAILED, CANCELLED |
| phase | TEXT NULL | SNAPSHOT, BLOBS, SEAL, VERIFY, STAGE, MIGRATE, COMMIT |
| progress_bytes / total_bytes | INTEGER | Nonnegative; total NULL when unknown |
| backup_id | TEXT NULL | Set on CREATE success; references `workspace_backup_manifests` |
| error_code | TEXT NULL | One of the promoted `BACKUP_*` codes |
| request_id | TEXT | Idempotency key scope with principal_id (UNIQUE) |
| created_at / updated_at | TEXT | RFC 3339 UTC |
| version | INTEGER | Increments on every state change; If-Match for cancel |

Partial unique index: at most one row with state in (QUEUED, RUNNING) per installation. No passphrase, key, path outside the archive file name, or row content is stored.

## 3. Lifecycle

```text
QUEUED -> RUNNING -> SUCCEEDED
                  -> FAILED     (typed error_code; partial archive deleted)
                  -> CANCELLED  (only before the commit point)
startup sweep: QUEUED or RUNNING from a previous incarnation -> FAILED (BACKUP_INTERRUPTED)
```

Manifest publication and SUCCEEDED commit in the same transaction. An archive file without a manifest is never listed. A manifest whose archive file is absent is listed as MISSING (observation only).

## 4. Archive content classes (B-41 PROPOSED)

| Class | Installation backup | Portable export |
|---|---|---|
| Workspace-scoped rows (per `BACKUP_WORKSPACE_SCOPED_TABLES`) | Carried | Carried |
| Other Workspaces' rows | Never | Never |
| Installation tables (`BACKUP_INSTALLATION_TABLES`) | Carried as metadata needed for foreign keys | Carried as metadata |
| Excluded tables (`BACKUP_EXCLUDED_TABLES`) | Never | Never |
| Blob envelopes | Copied verbatim with key references | Decrypted and re-encrypted inside the container; no key references |
| `RESOURCE_UPLOAD_CHUNK` bytes | Never | Never |
| Acknowledged purged content | Never | Never |
| Secrets (keyring, blob keys, provider credentials, SecretStore bytes, OAuth tokens, native handles, Runtime HMAC key, passphrase) | Never | Never |

## 5. Events

- `workspace.backup.created.v1` (PROPOSED): backup_id, workspace_id, mode, schema_version, integrity_digest, created_at. No path, no size of individual blobs, no key reference.
- `workspace.imported.v1` (PROPOSED): workspace_id, source backup_id, schema_version, revoked_grant_count, imported_at.

## 6. Retention and deletion

Archives are owner files: never auto-deleted or rotated in V1. Deleting an archive file does not delete the manifest (history); it marks it MISSING. Operation rows follow normal audit retention. Importing never deletes local data.

## 7. Migration

One forward-only migration adds `backup_operations`. Restoring an older-schema archive runs the normal migration chain on the staged copy only, before commit. No migration ships in IN_REVIEW.
